# Triage labels

This repo uses the triage skill's default five-role state vocabulary unchanged — no label remapping needed. Canonical role names match the actual GitHub label strings on `Nathapons/portfolio` exactly:

- `needs-triage`
- `needs-info`
- `ready-for-agent`
- `ready-for-human`
- `wontfix`

Category labels (`bug`, `enhancement`) also match the triage skill's canonical names as-is.
